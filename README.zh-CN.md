# Tesla-UI-prototype

[English](README.md) · **简体中文**

特斯拉风格车机交互原型，用于探索浏览器中的车辆界面、交互动效和 3D 展示。

项目包含实时 Model 3 车模、3D 空调界面、前排座椅调节、模拟地图导航、车控设置和音乐播放器。界面以 **1920 × 1200** 为设计画布，随浏览器窗口等比例缩放。

这是独立设计原型，并非 Tesla 官方产品。车辆操作、路线、胎压和播放均为演示，不连接真实车辆、实时地图服务或音乐流媒体服务。

## 功能与交互

### 3D 车模

- 收起时采用固定俯视视角；展开后展示低角度前侧视角。
- **展开后**支持拖动及方向键旋转；停止旋转操作 5 秒后平滑返回默认视角。
- 双击车模，或聚焦车模后按 Home / Escape，可复位视角；不提供滚轮缩放。
- 前备箱、后备箱和充电口支持开合动画，Open / Close 按钮通过细线指向对应部位。
- 收起时前后备箱按钮位于车模右侧，充电口按钮位于左侧。
- 独立调整的车漆、玻璃、橡胶、灯光、地面照明与倒影；前后车灯保持开启。

### 空调与前排座椅

- 从底部弹出的空调抽屉，包含 3D 内饰、动态气流、可拖动的风向、风量、温度和空调开关。
- 主驾、副驾座椅提供正面及侧面视图，可通过交互手柄调整前后位置和靠背角度，不包含高度调节。
- 座椅位置保存在本地；调节靠背和切换座椅时保持稳定的模型比例。

### 地图导航

- 使用轻量图片底图，文字、地点、车标和路线保持独立的动态交互层。
- 支持拖动、缩放、回到当前位置、目的地搜索、充电地点、路线比较，以及开始和结束导航演示。
- 展开车模下方的 Navigate、Home、Work 与地图联动：收起车模后打开搜索或对应路线预览。
- 开始导航后车辆仍保持停车状态，不模拟行驶，也不提供实时路况。

### 音乐与 Dock

- 五首歌曲及封面，支持共享的选曲、播放状态、进度、上一首/下一首、收藏和队列选择。
- 左侧音乐卡片保留自己的详情和搜索交互；Dock 音乐图标打开**地图上方的独立播放器窗口**，两处状态同步。
- 点击扬声器弹出音量滑块，显示百分比并提供静音操作；Dock 同时保留音量逐级调节按钮。
- 前后除霜开关、选中状态、按下反馈，以及车控、空调、座椅和应用入口。
- App Launcher 显示作者头像、名字和联系方式。

音乐播放仅为界面演示，项目不包含音频文件或流媒体账号凭据。

### 车控设置

包含 **Controls、Autopilot、Lights、Locks、Display、Dynamics、Safety、Service** 八个分类。

可体验开关、分段选择、滑块、调节弹窗、演示钥匙管理、胎压展示、轮毂/轮胎配置和服务相关流程。车控偏好、演示钥匙及座椅位置通过浏览器 `localStorage` 保存，其他界面状态通常只在本次会话中保留。

## 技术栈

| 层级 | 技术 |
| --- | --- |
| 界面 | React 19、TypeScript 6 |
| 开发与构建 | Vite 8、npm 锁文件 |
| 样式 | CSS、CSS 变量/设计令牌、Tailwind CSS 4 |
| 3D | Three.js 0.186、glTF/GLB、Draco 压缩、WebGL |
| 动效 | CSS 过渡、基于 requestAnimationFrame 的场景与相机动画 |
| 导航 | 预渲染 WebP 底图与 SVG/DOM 交互图层 |
| 本地存储 | 浏览器 localStorage |
| 代码检查 | TypeScript 项目构建、ESLint |

运行不需要后端、API Key 或账号。模型和 Draco 解码器随仓库提供。主页面会向 Google Fonts 请求 Inter 字体，请求不可用时使用系统字体回退。

## 安装与启动

建议使用 **Node.js 24**，对应仓库中的 `.nvmrc`，并安装 npm。Vite 要求 Node.js `^20.19.0 || >=22.12.0`。浏览器需支持 WebGL 2 并开启硬件加速，才能显示 3D 场景。

```bash
git clone https://github.com/RyanZeeee/Tesla-UI-prototype.git
cd Tesla-UI-prototype
npm ci
npm run dev
```

也可以下载仓库 ZIP 并解压，在项目根目录执行最后两条命令。

开发服务通常自动打开 [localhost:5173](http://localhost:5173/)。端口被占用时，请使用终端实际输出的地址。使用 nvm 时，可先执行 `nvm use`。

### 常用命令

| 命令 | 用途 |
| --- | --- |
| `npm ci` | 按锁文件安装准确版本的依赖 |
| `npm run dev` | 启动开发服务并打开浏览器 |
| `npm run lint` | 执行 ESLint 检查 |
| `npm run build` | 类型检查并生成 `dist/` 生产文件 |
| `npm run preview` | 本地预览已生成的生产版本 |

```bash
npm run lint
npm run build
npm run preview
```

生产预览通常使用 4173 端口。请通过 HTTP 服务访问，不支持直接双击 HTML 使用 `file://` 打开。

## 开发说明

- 主要布局样式位于 `src/dashboard.css`、各功能的 CSS 文件及 `src/tokens.css`。
- 车辆、内饰和座椅渲染模块按需加载。车辆场景主要在加载、动效、交互和窗口变化时绘制，静止时不会持续运行渲染循环。
- 地图几何数据在离线阶段转换为 WebP 图片，降低运行时 SVG 复杂度。
- 界面按车机画布整体缩放，不是传统手机网页的响应式重排。推荐在较大的横屏窗口中体验。
- Python 及图片处理依赖仅用于**可选的资源制作**。地图图片和座椅模型已经生成，正常安装无需重新制作。

更多内容见[开发与资源工具说明](docs/development.md)、[3D 实现说明](docs/vehicle-3d.md)和[车控设置资料依据](docs/vehicle-settings-reference.md)。

## 部署

`npm run build` 生成可静态部署的 `dist/`，其中包含模型和解码器。将 **`dist/` 内的内容**发布到静态站点托管服务。

如果使用 GitHub Pages 的 `/Tesla-UI-prototype/` 仓库子路径，可执行：

```bash
npm run build -- --base=/Tesla-UI-prototype/
```

部署到域名根路径时使用普通构建命令。仓库未自动配置托管服务或 GitHub Pages 发布工作流。

## 常见问题

- **模型加载失败：** 检查浏览器硬件加速和 WebGL 支持，确认 `public/models/`、`public/draco/` 完整。修复后可点击模型重试入口。
- **部署后白屏或资源丢失：** 检查 Vite 的基础路径，并确认构建产物、GLB 和解码器一起部署。
- **界面看起来较小：** 扩大浏览器窗口，整个设计画布会按窗口比例缩放。
- **刷新后设置未重置：** 车控设置和座椅位置会保存在本地。需要完全重置时，可在浏览器开发者工具中清除此站点的本地存储。
- **构建提示大文件：** 3D 依赖会生成较大的代码块，单独的大文件警告不代表构建失败。

## 资源署名

车辆模型来自 TeslaHub 社区分发版本。模型内嵌元数据和分发仓库均标注 CC BY 4.0，但作者署名存在差异，项目保留了两份署名。座椅模型也由同一来源派生。详见[第三方资源说明](docs/third-party-assets.md)和[随仓库提供的模型来源页](public/models/credits.html)。

项目原始代码暂未指定统一的开源许可证。依赖与第三方资源分别遵循各自许可证；模型许可证不适用于音乐封面、参考图或 Tesla 品牌素材。本项目与 Tesla 无隶属或背书关系。
